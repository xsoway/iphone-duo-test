Why Duo Differs

Standard iPhone Baseline vs. iPhone Duo Variables

Dimension Standard iPhone iPhone Duo Variables Key Verification
Physical Display Single main screen Cover (A) ↔ Inner (B) Object ID, route stack, unsaved input
In-App Layout Single-window width Single-stack or list-detail dual-pane Default selection, CTA target sync
Half-Fold Hinge No hinge zone Segmented viewport & hinge gap (C) Controls & text avoid reserved area
System Multitasking Single-app window System Split View (D) side-by-side Left/right swap & keyboard focus
“Can you still see the page? Can you still tap the key control? And is the object you are acting on still the exact same one?”
