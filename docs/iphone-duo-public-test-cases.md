# iPhone Duo 折叠屏适配与兼容公共测试用例

更新日期 2026-11-25。共 **144 条公共测试用例**，包含 90 条通用化基线与 54 条补充用例。所有用例待项目执行。

## 执行矩阵

| 标记 | 环境或姿态 | 最低覆盖 |
| --- | --- | --- |
| A | 合盖外屏，单屏 | 冷启动、窄宽安全区、单栈导航、打开键盘 |
| B | 全展开内屏 | 单列自适应、应用内列表与详情双栏、图集或表格 |
| C | 半开内屏 | 书本或桌面等系统可提供的姿态，检查折叠保留区和控件 |
| D | 系统 Split View | 应用支持时，与另一 App 并排，交换左右和切焦点 |
| A↔B | 外屏和内屏双向切换 | 稳定态与交互中均测，至少含输入、滚动、弹窗和请求进行中 |
| 对照 | 普通 iPhone、Duo 实机 | 同版本同数据复测疑似兼容问题，验收真实硬件及分发流程 |

原始用例沿用 M1 至 M7。M1 合盖外屏，M2 完全展开，M3 合展切换，M4 半开，M5 旋转与方向锁，M6 可调整窗口与分屏，M7 系统生命周期。

iPhone Duo 的内屏和外屏是物理显示面，应用内双栏和系统 Split View 是两种窗口布局，半开还可能涉及内屏分段。按产品设计判定栏数、方向和留白。对 Safari 与 WKWebView 分别核对视口和可用能力。WebKit 说明 Safari 27.1 的姿态和视口分段 API 属于需开启功能开关的预览，用例包含默认配置下的降级检查。 [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo) · [WebKit Safari 27.1](https://webkit.org/blog/18486/webkit-features-for-safari-27-1/)

- 准备模拟器构建、固定对象 ID、A/B 测试账号、H5 测试 URL、已知哈希的测试文件、可控制响应的测试服务。写操作以测试环境中的业务记录、文件校验或事件 ID 验证。
- 每条记录写明设备、OS、构建、姿态及方向、前置数据、步骤、预期、实际、状态和证据。状态可用通过、失败、部分验证、待确认、阻塞、未执行、不适用。
- 先跑 P0。对布局问题同时记录当前活动显示面、控件实际热区和稳定画面。对数据问题记录对象 ID、切换时间和服务端结果。
- 模拟器可执行布局和交互回归。分发、真实 APNs、硬件输入、热量、电耗和发布性能按对应真机环境验收。
- 示例执行记录可写为 `PUB-001 | A 外屏纵向 | iOS 27.2 | 构建号 | 部分验证 | 截图与阻塞原因`。
